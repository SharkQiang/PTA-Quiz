## 这个 App 是什么

一个**纯离线**的 PTA T1 认证刷题工具。不联网、不注册、不收费、无广告，题库直接打包在安装包里。

| 功能 | 说明 |
|---|---|
| 随机刷题 | 可选「本地真题 / 网络补充 / 混合」与题量；整套 30 题满分 100 |
| 每日速记 | 默认 10 题，答对直接过，答错才询问是否记入错题本 |
| 错题本 | 按来源筛选；重刷答对自动移出，答错累计次数 |
| 题库检索 | 关键词 / 卷号 / 分类 / 来源 四维筛选 |
| 收藏夹 | 星标收藏，随时回看 |
| 统计 | 总正确率、分类薄弱项、近 7 天趋势 |

**题库规模**

- 本地真题：**300 题**（CCF PTA 第 1—10 次认证 T1 试卷，单选 200 + 多选 100）
- 网络补充：**60 题**（依据 CCF《PTA 标准（教学能力 T）》大纲自命题的衍生模拟题，**非官方真题**）
- 合计 **360 题**

**题型与计分**：单选 20 题 × 3 分 + 多选 10 题 × 4 分，满分 100。
多选**必须全对**才得分（漏选、错选均 0 分）。官方通过线 60 分，App 内默认及格线 80 分（可调）。
